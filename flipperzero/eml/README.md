# Email tester

This folder houses an email testing automation script

# [Disclaimer]

While these scripts are generally safe to use, please use caution before blindly running anything and review all scripts to be aware of what commands are running.

# Instructions

In order for this all to work, it's going to need some prep work.

C'Mon, it's not gonna be that bad.

For starters, if there is not already. Either download or copy an image you would like to use for testing. Name the file something like "testing.jpg". We want it to be easily searchable. 

Next, set the email you want to send to in email.txt. Unless you want to send your test message to some random email.

Once that is done, the test should be ready to be run. Simply plug your Flipper Zero into your PC and locate email.txt. This test will use Firefox as the default browser and Gmail.

Helpful tip: Close out all of your windows except for your web browser so no open other windows interfere with the script being run.
