# Welcome to /ps1/sys

This folder contians various system tasks, ranging from quick disk space checks to hash comparisons of a directory.

# Contents

gdrive.ps1 - get drive space information for current system

hash.ps1 - compares the hashes of all files in a directory

log.ps1 - parses recent log files

netstr.ps1 - [Windows only] checks the wireless network strength of current device

rangscan - scans all local IPv4 addresses within a certain range

top.ps1 - emulates the top command from Linux
